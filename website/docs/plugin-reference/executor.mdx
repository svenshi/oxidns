---
title: 执行器插件
sidebar_position: 3
---

执行器是 OxiDNS 的核心动作层。它们可以读写请求、设置响应、调用上游、缓存结果、做回退、记录日志，或触发系统联动。

阅读本章时，应重点关注以下两个问题：

1. 这个插件是在“正向阶段”生效，还是在“回程阶段”也会改写结果？
2. 它是主路径动作，还是观测/副作用动作？
