OxiDNS 的管理 API 是独立控制平面，提供健康检查、配置校验与保存、进程控制、日志、升级、插件扩展 API 和 Prometheus 指标。本页是接口地图；请求格式、返回字段和示例分别位于专题页。

## 使用顺序

1. 按[访问约定与安全](api/conventions.mdx)配置监听、TLS、Basic Auth、CORS 和 WebUI。
2. 用 `GET /api/healthz` 检查监听，再用 `GET /api/readyz` 判断 DNS 服务是否就绪。
3. 修改配置前调用校验接口；保存后通过 reload 接口应用，并轮询 reload 状态。
4. 只向可信网络暴露控制、日志、升级和插件数据接口。
5. 将 `/api/metrics` 接入 Prometheus 时，保持与管理面相同的访问控制边界。

## 兼容性说明

管理 API 属于当前二进制的控制面能力。部署自动化应先读取 `/api/build` 确认 bundle 和插件能力，并容忍可选插件路由不存在。升级前后请重新执行 readiness、配置校验和关键 API 冒烟测试。
